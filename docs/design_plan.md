# ShopImpact multi-page design

## Purpose and guardrails

The redesign keeps the established Obsidian, Ivory and High contrast identity, vector Tilly, category tiles and monthly hero ring while splitting the former long screen into focused pages. It preserves purchase and plan data, calculations, badges, exports, privacy boundaries, keyboard access, the Reduce motion setting and supportive, non-judgmental language. All CO₂e values remain illustrative estimates, not measured product data or life-cycle assessments. `logic.py` was not changed.

## Information architecture

```text
Shared sticky top bar
├── Home                   purchase inputs → monthly snapshot → narrow side companion
├── Dashboard              KPIs → chart toggle/forecast → insights and goal momentum
├── Purchases              journal → filters/edit/undo → recurring and CSV tools
├── Swaps and plan         top alternatives → comparison/what-if → plan lifecycle
├── Garden and badges      Tilly → garden/footprints → badges/challenges/XP/inbox
├── Month in review        story cards → share image/PDF/poster
└── Settings and about     display/accessibility → data controls → privacy and method
```

`app.py` is the short router. It calls `st.set_page_config`, initializes shared session state, registers `st.Page` objects with Streamlit 1.65.0 `st.navigation`, renders shared styles/top bar/browser storage once, then runs the selected page. Every route is implemented by one `render()` function in `views/`. `ui/common.py` owns shared page headers, navigation, preference controls, persistence and reusable UI helpers. Each route reads the same `st.session_state`; browser-local persistence carries preferences, purchases, plans, onboarding and achievements across refreshes.

## Page layout and design system

Home retains the assignment layout: inputs at the top; a compact month snapshot with estimate, ring, three stat chips and goal progress in the centre; Tilly, the latest Turtle drawing, footprint trail, newest badge and tip in a narrow side column. A low-impact log shows its eco-win sprout immediately. The other pages move existing features rather than dropping them. Dashboard uses three stat chips; Purchases owns journal maintenance and import/export; Swaps and plan contains comparison and scenario tools; Garden and badges owns progress art and rewards; Month in review owns sharing/downloads; Settings and about owns display and data controls.

The top bar keeps branding left, registered `st.page_link` navigation in the centre, and month/Settings controls to the right; on mobile it uses the compact menu. Page titles are native `st.Page` titles. A common page header, primary action, skip link, landmarks, and “What’s next” nudge establish a predictable rhythm. `styles.css` contains the shared palette, typography, focus indicators, theme variants, responsive layouts and motion rules. Product tiles use six columns at 1280px, three at 768px and two at 360px; the final two tiles expand to fill their row. The redundant padding below the fixed top bar was reduced.

The locally bundled Source Sans 3, Source Serif 4 and Atkinson Hyperlegible fonts avoid external font requests. Ivory and Obsidian use restrained surfaces and accents; High contrast remains intentionally black/white with a vivid accent. Text and labels accompany color. The browser matrix checks all seven pages in all three modes at 360, 768 and 1280 CSS pixels.

## SVG and Turtle graphics

Tilly is generated by `tilly_svg.py`, with five moods, themes and motion-aware output. `ui.common.render_tilly` embeds base64 SVG images and keeps the speech bubble in the surrounding page. System reduced motion selects a separate static `<img>` through host-page CSS; the browser does not consistently apply the page's media preference inside a data-URI SVG image. The app Reduce motion setting also requests static SVG strings.

The on-screen growing plant/eco-win sprout, footprint trail and Eco Garden come from `SvgTurtle` in `turtle_svg.py`. It implements `forward`, `backward`, `left`, `right`, `circle`, `goto`, `begin_fill`, `end_fill`, `penup`, `pendown`, `pencolor`, `pensize`, `fillcolor` and `setheading`, records the pen path and emits animated SVG. `ui.illustrations` caches SVGs by inputs, theme and animation state. Ordinary month/page reruns preserve the garden/trail art; the eco-win SVG receives a purchase-ID XML comment so a newly logged low-impact purchase creates a new image identity. Original Pillow-backed `TurtleCanvas` drawings remain for badges and PNG export paths.

## Accessibility, motion and verification

- Keyboard-operable Streamlit controls retain visible focus; navigation includes a skip-to-content link and main/navigation landmarks.
- `prefers-reduced-motion` shows static mascot/Turtle SVG images through the shared page CSS. The in-app Reduce motion preference requests SVGs without animation styles.
- Axe runs on all 21 page/theme combinations. The test excludes only the known Streamlit 1.65.0 date-input `aria-allowed-attr` vendor node on Home; other violations fail. Automated contrast checks are representative, not a claim of exhaustive state-by-state WCAG AA certification.
- Playwright confirms the navigation/state refresh flow, no horizontal document overflow, 63 page screenshots and 72 timed drawing frames. `docs/test_log.md` records current test counts, measured SVG sizes, page-load timings, the Axe exception and outstanding phone checks.

## Remaining constraints

Streamlit still owns widget markup, so the app styles its semantic widgets rather than replacing them with a bespoke front end. The screenshot matrix uses a fresh empty journal; populated-data interactions are covered separately by Python and browser tests. Real-device Safari/Chrome checks and independent feedback from 2–3 users remain manual submission work. No school-specific rubric document was supplied; explicit task requirements are mapped in `docs/BRIEF_COMPLIANCE.md`.
