# Direct access and local saving

ShopImpact opens directly to the workspace. The previous Supabase email authentication flow has been retired from app navigation. The app no longer requires email confirmation, passwords, or an account service to use the journal.

Purchases and preferences stay in the current browser when storage is available. Download a backup before clearing browser data or moving devices. Shared browser profiles can expose their saved journal to other people using that profile. Hosted Streamlit sessions process active inputs on the app server. Ask Tilly sends data to its AI provider only after the existing consent step.
